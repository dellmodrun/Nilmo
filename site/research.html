How it works

Tesera is a hosted MCP gateway for on-chain networks, starting with Elysium. You add one URL to your AI client, and from then on you can ask it to read the chain, explain and simulate transactions, ship contracts, or act within limits you set. This page walks through what happens between your question and the answer.

Endpointmcp.teseralab.com/elysium
NetworkElysium mainnet
ReadsFree, and need no wallet
MCP in one paragraph

MCP, the Model Context Protocol, is an open protocol for connecting AI clients to tools. A client that supports it, such as Claude, Claude Code, ChatGPT, Cursor, VS Code or Devin Desktop, can be pointed at an MCP server and will then see that server's tools, with a description of what each one does and what it needs. When you ask for something, the AI decides which tool fits, calls it, and uses the answer in its reply. Tesera is an MCP server built for on-chain networks, and Elysium is the first network it serves.

01

The path of a request

What happens after you ask a question in your AI client.

01 · You ask

You type a request in your AI client in plain words, for example “why did my last deposit fail?”.

Your AI client
02 · A tool is picked

The client already knows Tesera's tools and their inputs, so the AI chooses the ones that fit, here elysium_get_transaction and elysium_trace_call, and fills in the hash.

MCP tool call
03 · Tesera works

Tesera runs the call against Elysium nodes, the block explorer and its index of the Elysium docs, decodes everything it can by name, and returns structured data the AI can read without guessing.

Elysium nodes, explorer, docs
04 · Back to you

The AI answers in the chat. If you asked it to move funds, the answer includes a prepared transaction and a plain preview of its effect, for you to check and sign.

03

How signing works

Tesera never holds private keys and never asks for a seed phrase.

Example in the default mode
You Send 25 HYPE to 0x7a3f...c91e AI calls elysium_prepare_transaction Tesera simulates it against live state to 0x7a3f...c91e value 25 HYPE fee from elysium_estimate_gas result succeeds, sends 25 HYPE You open the signing link, check it, sign in your wallet Wallet sends it to Elysium AI calls elysium_wait and reports the result
Default

Simulated, then signed by you

Anything that changes state comes back as an unsigned transaction with a plain preview of what it will do. You review it and sign it in your own wallet, and only then does Tesera broadcast it.

Optional

An agent key with limits

For agents that run without asking each time, you create an agent key in your own wallet, fund it and set hard limits. The agent can act inside those limits only, and you can revoke the key at any time.

Capper transaction and per day
Scopeallowed contracts and functions
Expirywhen the key stops working
Always

Checked twice

The signing page decodes and simulates the transaction again from the transaction itself, not from the AI's description, and checks the account and chain before your wallet sends it.
