Read

Look things up on Solana and in its documentation, from balances and blocks to verified source, proxies and live priority fees. These tools only read, so they are free to call and need no wallet.

Wallet

Not needed.

solana_get_balance

Returns the SOL balance and every token balance for an address.

AskHow much SOL does 7VbW…kP3 hold, and which tokens?
solana_get_transaction

Returns a transaction with its receipt, status and fees used.

AskWhat happened in transaction 5hQf…9mLs, and did it succeed?
solana_get_block

Returns a block by number, by hash, or the latest block.

AskWhat is in the latest block on Solana?
solana_read_program

Calls any view function using the published IDL, or an IDL you supply.

AskWho is the owner of the program at 7VbW…kP3?
solana_get_logs

Returns events filtered by event name, topics and block range, decoded by name.

AskShow me the Transfer events on this token over the last 1,000 blocks.
solana_token_info

Returns a token's name, symbol, decimals and total supply.

AskWhat are the symbol, decimals and total supply of 7VbW…kP3?
solana_program_info

Returns what is known about a program: verification status, compiler, IDL, proxy and implementation addresses, and the deployer.

AskIs 7VbW…kP3 verified, and is it a proxy?
solana_gas_price

Returns the current base fee and a suggested priority fee, with the cost of common actions in SOL.

AskWhat does a simple transfer cost right now?
solana_search_docs

Searches the Solana and ecosystem docs so the AI checks its answer against the source.

AskHow do I bridge SOL to Solana? Check the docs first.

Understand

See what a transaction will do before it happens, and what one did after it happened. This is what lets your AI explain the chain instead of guessing at it.

Wallet

Not needed. Nothing is sent.

solana_simulate

Runs a transaction against live chain state without sending it. Returns success or the exact revert reason, balance changes, events and fees used.

AskWhat happens if I call deposit on this vault with 100 SOL?
solana_decode_transaction

Breaks any transaction into plain parts: the function called, its arguments, token movements and the events it emitted.

AskExplain transaction 5hQf…9mLs in plain words.
solana_trace_call

Returns the internal call tree of a transaction, so a failure can be traced to the exact program and call.

AskWhich internal call made my last swap fail?

Build

Write, ship and verify programs from the chat. Nilmo starts from audited templates, prepares each deployment and simulates it, and you sign it in your own wallet.

Wallet

Your wallet signs each deployment.

solana_scaffold

Starts a program on OpenZeppelin bases, from tokens and vaults to agent wallets with session keys, escrow, bounty boards and subscriptions, set up with your parameters.

AskStart me an SPL Token called Orbit with a supply of 10 million.
solana_program_build

Builds Rust or Anchor source for Solana and reports diagnostics with line numbers.

AskCompile this program and tell me what is wrong with it.
solana_estimate_fees

Estimates the fees for a transaction or deployment and what it will cost in SOL.

AskHow much SOL will this deployment cost?
solana_deploy

Prepares a deployment for you to sign, simulated first so you see the result before you pay for it.

AskDeploy this program to Solana with my address as owner.
solana_verify

Verifies a program's source on the Solana explorer, including programs behind a proxy.

AskVerify the source of the program I just deployed.

Act

Turn a plain request into a transaction, preview it, send it once it is signed and wait for the result. Agents running on their own act through an agent wallet with session keys, inside the limits you set.

Wallet

You sign in your own wallet, or a session key on an agent wallet you deployed acts within its limits.

solana_prepare_transaction

Builds an unsigned transaction from a plain request, simulates it, and returns a preview of exactly what it will do.

AskSend 25 SOL to 7VbW…kP3.
solana_prepare_batch

Builds a sequence of transactions, such as an approval followed by a deposit, and simulates them in order.

AskApprove this vault and deposit 500 of my tokens.
solana_send_signed

Broadcasts a transaction you have signed. Sending the same signed transaction twice is safe.

AskI have signed it, please send it.
solana_wait

Waits for a transaction to confirm and returns the result, decoded.

AskLet me know once it is confirmed.
solana_key_status

Reads a session key's limits on an agent wallet from the program: whether it is active, when it expires, the SOL and tokens it can still move today, and the functions it may call.

AskHow much can my agent's session key still spend today?
solana_agent_wallet

Creates an agent wallet you own and grants session keys within limits you set: allowed functions, SOL per transaction and per day, token caps and an expiry, all enforced on chain. The agent then acts by signing with its key.

AskMake my agent a wallet it can trade from, up to 5 SOL a day, for the next 24 hours.

Agents

Give agents an identity other agents can check. Register an agent on Solana with its services and endpoints, find agents by owner or by what they do, and rate them after working with them, on Solana agent identity, the open standard for trustless agents. Pay and hire agents through escrow, watch any program, respond to it on their own with prepared transactions, and query its full history.

Wallet

Lookups need none. Registrations, ratings and payments are prepared for the right person to sign.

solana_agent_register

Prepares an on-chain agent registration with its name, description and services such as MCP, A2A or web, or updates an existing one.

AskRegister my agent Scout, with its MCP endpoint at scout.example/mcp.
solana_agent_lookup

Finds agents by ID, owner or keywords, with their services, wallet and reputation: average score, number of reviewers and recent feedback.

AskFind an agent that translates docs, and show me its reviews.
solana_agent_feedback

Prepares a rating for an agent after working with it, with optional tags such as quality or speed. Owners cannot rate their own agents.

AskRate agent 12 a 90 for quality.
solana_agent_pay

Pays an agent at the wallet it registered, once or on a schedule, in SOL or any token.

AskPay agent 12 five USDC every week.
solana_agent_job

Hires an agent through escrow: funds held until the work is in, with a deadline, a review window, refunds and an optional arbiter.

AskHire agent 12 to translate the docs for 50 USDC, due in two days.
solana_watch

Watches a program and reports matching events as they happen, by signed webhook or for your agent to poll, with filters, minimum amounts and presets for ownership changes, upgrades and large transfers.

AskTell me whenever more than 10,000 USDC moves in one transfer.
solana_react

Lets your agent respond to the chain on its own. When an event happens, tokens arrive or a Jupiter Swap price crosses a level, Nilmo prepares the response with another tool, checks it with Nilmo Shield and hands it over ready to sign.

AskWhenever my agent receives 100 USDC, prepare a swap of half into SOL.
solana_index

Indexes a program's whole event history and keeps it live, so your agent can filter, count, sum and rank it in one call.

AskWho sent the most USDC through this program last week?

Perps

Read, test and plan Drift perp trades from the same chat. Market data, funding across venues, account risk and backtests are free to call. Trades are planned with a stop and sent only once you sign them, or through an agent key that can trade but can never withdraw.

Wallet

Reads need none. Trades are signed by you, or by an agent key you approved.

solana_perps_markets

Lists every Drift perp with price, 24h change, funding, open interest, volume and max leverage, including builder-deployed HIP-3 markets.

AskWhich perps pay the highest funding right now?
solana_perps_market

One market in depth: the order book, USD depth within 10, 50 and 100 bps, what a 10k to 1M USD market order would slip, and funding now and predicted on Drift, Binance and Bybit.

AskHow deep is the BTC book, and what would a 1M USD buy cost me?
solana_perps_account

An account's value, margin, positions with PnL and distance to liquidation, open orders, fills, funding and fees. Flags positions near liquidation or without a stop.

AskCheck my Drift account. Is anything close to liquidation?
solana_perps_funding

Hourly funding history for one market, or predicted funding for every market across Drift, Binance and Bybit.

AskWhat has ETH funding looked like this week?
solana_perps_candles

Price candles from one minute to one week, with change, range, volatility and ATR.

AskShow me SOL on the four hour chart for the last month.
solana_perps_risk

Stress tests an account against BTC moves, finds the move that liquidates it, and reports one day VaR and expected shortfall from history.

AskWhat BTC move would liquidate my account?
solana_perps_plan

Plans a trade sized in coins, in USD or by what you are willing to lose at the stop, with a stop loss and take profit, and prepares it for signing.

AskLong SOL, risk 200 USD, stop 4% below entry.
solana_perps_scan

Scans every market for funding carry, funding gaps against Binance and Bybit, premiums, big movers and crowded positioning.

AskFind me the best funding carry right now.
solana_perps_backtest

Backtests moving average, breakout, RSI and funding carry rules on Drift history, with taker fees and real hourly funding.

AskBacktest a 20 and 50 moving average cross on BTC over 90 days.
solana_perps_agent

Shows the agent keys on an account, or prepares the approval for a new one. Agent keys can trade but can never withdraw.

AskWhich agent keys can trade my account?
solana_perps_submit

Sends a signed order, cancel or leverage change to Drift after checking who signed it. It never forwards withdrawals or transfers and blocks orders far from the mark.

AskSend the order my agent just signed.

Privacy-aware tools

Pay and get paid on Solana without a public link between sender and recipient, built on privacy-aware local preparation. Note secrets and proofs are made in your browser and never reach Nilmo.

Wallet

Deposits are signed in your own wallet. Withdrawals are proven in your browser and sent through a relayer.

solana_private_pool

Shows the private pools, their assets and fees, and how many approved deposits each one holds.

AskHow big is the SOL pool right now?
solana_private_deposit

Prepares a deposit into a private pool. The note secret is made in your browser, never by the AI.

AskDeposit 5 SOL privately.
solana_private_withdraw

Plans a withdrawal to any address, checks it for privacy leaks first, and relays proofs made in your browser.

AskWithdraw 2 SOL to a fresh address.
solana_private_invoice

Lets an agent get paid privately. The recipient makes an invoice, the payer's agent pays it, and only the recipient can withdraw it.

AskMake me a private invoice for 20 SOL.
solana_private_risk

Checks a planned withdrawal for anything that would link it to the deposit, such as a small crowd, a matching amount or withdrawing too soon.

AskIs it safe to withdraw now?
solana_private_disclose

Verifies spent notes that a user chose to share with an auditor or an exchange.

AskVerify the disclosure this counterparty sent me.
solana_private_session

Runs an agent task from a fresh, privately funded address, then sweeps what is left back into the pool.

AskRun this task from a burner address.

Jupiter Swap

Trade, provide liquidity and build hooks on Jupiter routing on Solana. Basic tools find pools, quote and swap. Medium tools manage positions and open new pools. Advanced tools write, deploy and inspect hooks and model a position before you commit to it. Every transaction is simulated and checked by Nilmo Shield before you sign.

Wallet

Reads need none. Swaps, liquidity, pools and hook deployments are signed in your own wallet.

solana_jupiter_pools

Basic. Every pool for a pair across fee tiers and hooks, with price, liquidity and what each hook is allowed to do.

AskWhich Jupiter pools trade SOL against USDC?
solana_jupiter_quote

Basic. Quotes a swap with Jupiter's own quoter, compares direct and two-hop routes and reports price impact. Skips pools whose hooks can move swap value unless you allow them.

AskHow much USDC would 50 SOL get me on Jupiter?
solana_jupiter_swap

Basic. Prepares the swap through the Universal Router with slippage protection, a deadline and only the approvals still missing.

AskSwap 50 SOL for USDC, at most 0.5% slippage.
solana_jupiter_positions

Medium. Your liquidity positions: range, whether they are earning, what they hold now and uncollected fees.

AskAre my Jupiter positions still in range?
solana_jupiter_liquidity

Medium. Adds liquidity full range, around the price or between two prices, adds to a position, removes part or all of it, or collects fees.

AskAdd 1,000 USDC of liquidity within 10% of the current price.
solana_jupiter_create_pool

Medium. Opens a new pool at a starting price, with any fee, an optional hook, and the first liquidity in the same transaction.

AskCreate a pool for my token against USDC at 0.25, with 50,000 tokens.
solana_jupiter_hooks

Advanced. Five hook templates (volatility fee, launch guard, holder discount, volume points, TWAP oracle), or your own. Compiles it, finds an address that carries exactly its permissions and prepares the deployment. Inspect tells you what any hook can do.

AskDeploy a launch guard hook for my token's pool.
solana_jupiter_analytics

Advanced. Volume, fees, swaps and price range for a pool from on-chain events, plus a position model: share of fees, fee APR and impermanent loss across price moves.

AskWhat would a 5,000 USDC position within 10% earn in this pool?

Raydium LaunchLab

Raydium LaunchLab is a Jupiter Swap launchpad whose pools all run on one shared hook, each with Hook Blocks frozen at launch: a surge fee, Auto Burn, LP Rewards, a royalty, King of the Pool and arb recapture. These tools read the blocks in plain words, quote and trade through Raydium LaunchLab's own quoter and router so every block's take is included, and prepare token launches. Every transaction is simulated and checked by Nilmo Shield before you sign.

Wallet

Reads and quotes need none. Swaps and launches are signed in your own wallet.

solana_Raydium LaunchLab_pools

The newest Raydium LaunchLab pools, or one pool's Hook Blocks in plain words with its frozen limits, arb recapture and the current King of the Pool round. Also what a wallet can claim.

AskWhat Hook Blocks does this Raydium LaunchLab token run, and can they change?
solana_Raydium LaunchLab_quote

Quotes a buy or sell with Raydium LaunchLab's own quoter, so the result includes the fee at that size, what each block takes and what is burned.

AskHow much of this token do I get for 0.01 SOL after its hook takes its cut?
solana_Raydium LaunchLab_swap

Prepares the trade through Raydium LaunchLab's router with a minimum out, a deadline, the approval if one is missing and the fees an arb recapture pool requires.

AskBuy 0.01 SOL of this Raydium LaunchLab token.
solana_Raydium LaunchLab_launch

Prepares a token launch: one billion tokens in a locked pool against SOL, opening at the market cap you set, with the Hook Blocks you choose, including an Anti-Snipe launch guard. Settings are checked against Raydium LaunchLab's bounds and frozen when the pool opens.

AskLaunch a token called Lantern on Raydium LaunchLab at a 300 SOL market cap with a 1% burn.

Jupiter Routing

Jupiter Routing is the routing layer behind Solana's official bridge. These tools find the best route from any token into any token or DeFi position, bring tokens over from Ethereum in one signature, and run several steps as one transaction that fully succeeds or does nothing. Every transaction must go to Jupiter Routing's own router, or Nilmo refuses it, and each is simulated and checked by Nilmo Shield before you sign.

Wallet

Quotes, balances and token lists need none. Routes and bundles are signed in your own wallet, or by an agent's session key within its limits.

solana_Jupiter Routing_route

The best route between any two tokens or positions on Solana, or from Ethereum into Solana in one signature, straight into an agent wallet if you like. Also reads balances with USD values, lists what Jupiter Routing can route into, and tracks cross-chain delivery.

AskBring 5 SOL from Ethereum into my agent wallet on Solana.
solana_Jupiter Routing_bundle

Several steps in one atomic transaction: split one token into a basket, sweep leftovers into one token, a swap that reverts unless it returns a minimum, or raw Jupiter Routing actions chained together.

AskSplit 10 SOL into 50% USDC and 50% of this token in one transaction.

Kamino

Kamino turns a Orca Whirlpools position into fixed yield. In each vault the fixed side provides the position and is paid a premium upfront, and the fee side pays that premium for every trading fee the position earns over the term. These tools read the vaults, weigh the fixed rate against what the pool has really been paying, take either side, collect, and turn any v3 pool into a new vault.

Wallet

Reading and weighing vaults needs none. Deposits, claims and new vaults are signed in your own wallet, or by an agent's session key limited to one vault.

solana_Kamino_vaults

Vaults in plain words: pool, range, term, premium, the fixed rate a year and how full each side is. Also a wallet's positions and what it can do with each now.

AskWhich Kamino vaults are filling, and what do they pay?
solana_Kamino_price

Weighs a vault's fixed rate against the fees its pool has actually paid, with the break-even volume and which side comes out ahead.

AskIs the fixed side or the fee side the better deal on this vault?
solana_Kamino_deposit

Takes the fixed side or the fee side of a vault that is still filling, wrapping SOL when needed.

AskBuy the fees on this vault with 2 SOL.
solana_Kamino_claim

Whatever is due now: a deposit back before the start, the premium once it starts, liquidity and fees after the term.

AskClaim whatever I can from my Kamino vaults.
solana_Kamino_create

Turns any v3 pool into a fixed-yield vault and funds the fixed side, in one signing.

AskOffer 50 wSOL of liquidity in this pool at a fixed 30% for a week.

True of every tool

The rules Nilmo keeps for all of them

01

Simulated before signing

Anything that changes state is run against live state first, and you see the result in plain words.

02

Your keys stay in your wallet

Nilmo never holds private keys and never asks for a seed phrase.

03

A link to sign

Every prepared transaction comes with a signing link that checks it again before your wallet sends it.

04

Same shape on every network

Tool names, inputs and outputs stay the same as Nilmo adds networks, so your agents carry over.

Add MCP endpoint coming soon as a remote MCP server in your client. Setup for each client is in the quickstart, and every input and output is in the tool reference.
