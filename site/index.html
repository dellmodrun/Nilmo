Test the transaction.

Give Nilmo base64 transaction bytes to simulate against live Solana state. It returns logs, errors and compute use without signing or sending the transaction.

Look up transaction status, fees, instructions, balance changes and program logs using a Solana signature. Nilmo returns structured chain data to your AI client.
