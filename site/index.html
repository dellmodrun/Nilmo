The MCP gateway for on-chain networks

Talk to Elysium
from any AI.

Nilmo connects AI clients to blockchains through one URL, starting with Elysium. Your AI can read the chain, simulate and explain transactions, ship contracts and act within limits you set, while every signature stays yours.

01 · Read

Ask Elysium
anything.

Balances, blocks, events, contract state and verified source, read live from Elysium mainnet. Your AI checks the Elysium docs in the same step, so answers come from the chain and the source instead of a guess.

02 · Clients

Works with the AI
you already use.

Claude, Claude Code, ChatGPT, Cursor, VS Code and Devin Desktop all connect with the same URL. Add it once and every chat after that can reach Elysium.

03 · Control

Simulated first.
Signed by you.

Every transaction is run against live state and explained in plain words before you sign it in your own wallet. Agents that run on their own use an agent wallet with session keys and the limits you set: spend caps, allowed contracts and functions, and an expiry.

04 · Build

From a prompt
to a live contract.

Start from audited templates, compile, check the cost in HYPE, deploy and verify without leaving your editor. Your AI waits for the transaction to land and reads the new contract straight back.
