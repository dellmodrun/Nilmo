Setup

There is no sign-in and no key to paste. Add the URL and start asking.
01

Setup at a glance

01Claude

Open Customize, then Connectors, and choose Add custom connector. Name it Nilmo and paste https://mcp.teseralab.com/elysium. On Team and Enterprise plans, an owner adds it under Organization settings, Connectors. In a chat, turn it on from the + menu under Connectors.

02Claude Code

Run this once in your terminal: claude mcp add --transport http tesera https://mcp.teseralab.com/elysium. Add --scope user to use it in every project, and run claude mcp list to check it.

03ChatGPT

Open Settings, then Apps, then Advanced settings, and turn on Developer mode. Choose Create app, name it Nilmo and paste https://mcp.teseralab.com/elysium. Developer mode is on the web for Plus, Pro, Business, Enterprise and Education plans.

04Cursor

Open Customize from the sidebar, or run Open Customize from the command palette, and add a custom MCP server with the URL https://mcp.teseralab.com/elysium. You can also add "tesera": { "url": "https://mcp.teseralab.com/elysium" } under mcpServers in ~/.cursor/mcp.json, or in .cursor/mcp.json for one project.

05VS Code

Run MCP: Add Server from the Command Palette, choose HTTP, paste https://mcp.teseralab.com/elysium and choose Global when asked where to save it. You can also add "servers": { "tesera": { "type": "http", "url": "https://mcp.teseralab.com/elysium" } } to .vscode/mcp.json. The tools then appear in the Chat view.

06Devin Desktop

Add "tesera": { "url": "https://mcp.teseralab.com/elysium" } under mcpServers in ~/.config/devin/mcp_config.json on Mac and Linux, or %APPDATA%\devin\mcp_config.json on Windows.

Client menus change between versions. If a step does not match what you see, look for the place where your client adds a remote MCP server.

02

Any MCP client

MCP is an open protocol for connecting AI clients to tools, so Nilmo will work with any client that can add a remote MCP server over HTTP. Add the URL below, give the server a name such as tesera, and start a new chat or session so the client loads the tools.

Every tool is free to call, and reads need no wallet. Agents that make a lot of calls can add an optional access key for higher limits. When the AI wants to change something on chain, it prepares an unsigned transaction with a signing link, and you review and sign it in your own wallet. Nilmo never holds private keys and never asks for a seed phrase.

Endpoint https://mcp.teseralab.com/elysium

Live on Elysium mainnet. Every client uses the same URL.
